# Video Publisher Skill

面向 Codex 的视频发布 Skill：将同一条本地视频安全地发布到小红书、抖音和视频号。它会在每个平台内核验视频、文案、话题、声明、定时与最终发布结果，而不是只把“点击成功”当作发布成功。

## 支持的平台

| 平台 | 发布能力 | 关键行为 |
| --- | --- | --- |
| 小红书 | 视频笔记 | 原创可选、AI 声明、真实话题实体、定时发布 |
| 抖音 | 视频作品 | 上传优先启动；在已核验表单后可于上传中提交 |
| 视频号 | 动态视频 | 短标题、商品链接、AI 标注、定时发布 |

不支持 B 站或其他未列出的平台。

## 使用前准备

- macOS 设备与 Codex；本项目通过 Ego Lite 控制发布页面，当前不支持 Windows 或 Linux。
- 已登录自己拥有的小红书、抖音或视频号创作者账号；不使用通用“本地浏览器”控制方式。
- 已登录自己拥有的小红书、抖音或视频号创作者账号。
- 视频文件在本机，并拥有发布素材、原创声明和商品链接所需的权利。
- 首次运行会在本机建立个人配置；账号登录状态、视频路径和发布任务状态不会写入本仓库。

## 安装

在 Codex 新建对话并发送：

```text
请安装这个 Skill：
https://github.com/ShenTuZ/video-publisher-skill
```

安装后在下一轮对话中使用 `$video-publisher`。首次运行会询问你实际拥有的平台、默认平台和视频目录。

## 最小使用方式

```text
使用 $video-publisher 发布 /绝对路径/视频.mp4
非原创，不含 AI，立即发布，无商品
```

只需要补充和默认值不同的部分：

```text
使用 $video-publisher 发布 /绝对路径/视频.mp4
原创，含 AI，今日 20:00 发布，视频号挂第一个商品
```

未说明时，默认值为：非原创、不含 AI、立即发布、视频号不挂商品、平台默认封面、公开可见。视频号短标题会自动生成并控制在 10 个字以内且不含特殊字符。

## 发布流程

1. 检查本地视频和每个平台的发布前条件。
2. 选中抖音时，先启动抖音上传；随后启动小红书和视频号上传。
3. 仅保留一个表单控制器：抖音 → 小红书 → 视频号，后台上传继续进行。
4. 抖音在上传中满足全部非视频条件时可提前提交；小红书和视频号等待各自上传完成。
5. 每个平台独立达到 `READY` 后才允许最终发布，并读取明确的平台成功信号。
6. 已发布的平台是终态；同一任务重跑时会永久跳过它。

自动发布只会在当前任务明确要求或个人配置已明确开启时执行。需要人工复核时，要求 Skill 停在 `READY` 即可。

## 常用输入

| 需求 | 示例 |
| --- | --- |
| AI 内容 | `含 AI` / `不含 AI` |
| 原创声明 | `原创` / `非原创`（仅小红书和视频号） |
| 定时 | `今日 20:00 发布` |
| 视频号商品 | `挂第一个商品` |
| 只做草稿核验 | `停在 READY，不发布` |
| 只跑一个平台 | `只发布抖音` |

抖音没有“是否原创”控件，因此不会把原创指令映射为抖音声明。

## 安全与隐私

- 不保存 Cookie、Token、密码、账号信息或视频路径到仓库。
- 不转码、不修改视频规格，也不自动替换素材。
- 找不到精确的商品、AI 声明、定时控件或成功证据时，会停止该平台，不猜测选择。
- Ego Lite 通道异常会在同一任务内有限重试；不会对活动上传重复注入，也不会重新进入已发布平台。
- 请不要把视频、截图中的私人信息、登录信息或商品后台数据提交到 Issue。
